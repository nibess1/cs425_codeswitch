\section{Experimental Setup}
\label{sec:setup}

\paragraph{Model.}
Whisper~\citep{radford2023whisper} is a Transformer encoder--decoder. The encoder reads an 80-bin log-Mel spectrogram of a 30\,s window (all our clips are shorter, so no chunking is needed); the decoder writes byte-level BPE tokens, starting with a language token. We use tiny (39M parameters, 4+4 layers), base (74M, 6+6) and small (244M, 12+12), on 16\,kHz mono audio.

\paragraph{Training.}
We fine-tune tiny, base and small on ASCEND and NSC training data together, updating all weights (Table~\ref{tab:hparams}). The loss weights were chosen on base by grid search on validation ($\alpha \in \{0.5,1,2\}$, $\beta \in \{0,0.5\}$, then $\lambda \in \{0.1,0.3\}$, $\rho_0 \in \{0.2,0.5\}$) and used unchanged for small. The gate threshold was chosen from $\theta_{\text{gate}} \in \{0, 200, 400, 800, \infty\}$\,ms; 200\,ms won for every model. Every selection rule was written down before any test result was seen. Each system is trained once; retraining the same base system with the same settings moved test MER by at most 0.2 points (Appendix~\ref{app:tl}).

\paragraph{Quantization.}
On GPU we use bitsandbytes LLM.int8~\citep{dettmers2022llmint8} and NF4 on all linear layers, compared with the 16-bit model. On CPU we use CTranslate2 int8 (compared with CTranslate2 float32) and whisper.cpp Q8\_0, Q5\_0 and Q4\_0 (compared with whisper.cpp F16). CPU rows use a fixed subset of the test sets: all of ASCEND test, 4{,}000 NSC Same Room and 2{,}000 Different Room utterances.

\paragraph{Decoding, hardware and code.}
Decoding is greedy with a 128-token cap unless stated. Hugging Face and CTranslate2 restrict the language token to Mandarin or English; whisper.cpp chooses among all languages. Training used one NVIDIA L40S GPU. Speed is measured on a MacBook Pro (Apple M2 Pro, 4 threads) on 100 test clips (259\,s). All code is in one repository; each step (pre-processing, training, testing, scoring) reads and writes plain files and can be rerun on its own, and \texttt{score.py} produces every number in this report. Appendix~\ref{app:run} lists the commands.
